# OSCP Learning Strategy

# Core Principle

Learn operationally.

Do not optimize for:
- reading completion
- theoretical memorization

Optimize for:
- execution
- troubleshooting
- adaptation
- repeatability

---

# Execution Model

Study → Practice → Note → Refine

---

# Learning Rules

## Every Topic Must Become:

- command
- workflow
- checklist
- decision tree
- exploitation path

---

# Important Mindset

Failure is expected.

OSCP rewards:
- persistence
- enumeration
- adaptation

NOT memorization.

---

# Practical Learning Strategy

## Daily Workflow

1. Study concept
2. Execute commands
3. Break things
4. Fix issues
5. Update notes
6. Repeat from memory

---

# Important OSCP Principle

Enumeration is more important than exploitation.

Most failures occur because:
- service was ignored
- output misunderstood
- attack path missed

---

# Cognitive Load Reduction

Good notes reduce:
- stress
- tunnel vision
- repeated mistakes

---

# From OffSec Training Philosophy

- Learning happens through difficulty
- Troubleshooting is part of training
- Repetition creates operational fluency
- Context matters more than memorization

---

# Critical Rule

Never copy commands blindly.

Always understand:
- what the command does
- why it works
- what output matters
- what the next pivot is
