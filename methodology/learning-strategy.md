# OSCP Learning Strategy

## Principles

- Learn by doing, not reading
- Expect failure and dead ends
- Iterate methodology constantly

## Execution Model

Study → Practice → Note → Refine

## Rules

- No passive reading
- Every concept must become a command or checklist
- Notes must be executable

## Weekly Cycle

- Learn new topic
- Apply on lab/box
- Update notes
- Consolidate
